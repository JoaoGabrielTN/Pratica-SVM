# Pratica-SVM
Este repositório contém o código criado para o projeto de
tópicos avançados em IA II. O objetivo deste projeto é realizar
um experimento prático utilizando a técnica SVM (_Support Vector Machines_)
## Informações úteis
- Dataset: Heart Faliure Clinical Records
- Nº instâncias: 299 pacientes
- Nº _features_: 12 
- _Target feature_: Death_Event
